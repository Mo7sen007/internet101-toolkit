Station: Web Server

This page came from your own laptop.

A browser on this machine opened a TCP connection, sent an HTTP request for /, and this file came back. No cloud, no data centre — just a few hundred lines of Go on your local network.

What just happened?

Your browser resolved a hostname to an IP address, connected to port 8080, and sent something like:

GET / HTTP/1.1

The server answered with headers and this HTML file. Look at the server terminal — the request is printed there.

Your turn

  • Edit public/index.html and refresh.
  • Drop an image into public/ and embed it.
  • Open /__workshop to watch requests arrive.
  • Run the server with --raw and connect with nc.
