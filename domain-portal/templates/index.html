How this works

  1. 1You register a name here. The portal sends it to the DNS server's API.
  2. 2The DNS server stores name.{{ tld }} → your IP in memory, with TTL 0.
  3. 3Your browser asks the Pi "where is name.{{ tld }}?" and gets your address back.
  4. 4The browser connects to port 8080 on your laptop, where the mini HTTP server is running.

Tip: keep the mini HTTP server running on your laptop while you demo. You can open any domain at http://name.{{ tld }}:8080.
