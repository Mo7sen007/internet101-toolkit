How the index is built

  1. 1The crawler asks the DNS server which .web domains exist.
  2. 2It fetches each site on port 8080 and follows links, avoiding loops.
  3. 3Titles, meta tags and body text are stored in index.db.
  4. 4Searches are scored with TF-IDF, so rare words rank higher.
